# Product Spec

Build a polished, responsive bilingual website for 7 Korean Bakery / 일곱시 떡집, a Korean rice cake bakery in Coquitlam, British Columbia.

Use the attached original bakery logo prominently in the desktop header, mobile header, and homepage hero. Preserve its proportions. Do not redraw, reinterpret, or replace it.

## Visual identity

Create a warm, calm, welcoming Korean identity with modern, clean layouts and subtle traditional details.

Use:

- Warm ivory: #FAF7F0
- Soft beige: #E8DDCF
- Muted sage: #A9B19B
- Deep brown: #4A3A30
- Soft dusty rose: #D8B7AE
- Noto Serif KR for headings
- Noto Sans KR for body text

Use generous whitespace, subtle borders, restrained decoration, and accessible contrast. Avoid stock food photography, invented food images, heavy animation, luxury-hotel styling, and generic Western bakery aesthetics.

## Pages and navigation

Create exactly four main pages:

1. Home
2. Custom Order
3. Find Our Products
4. Gallery

Include an English / 한국어 toggle. Translate navigation, content, form labels, validation, notices, and confirmation messages. Use a compact sticky header and accessible mobile navigation.

Do not create a separate public Menu page, checkout, payment processing, customer accounts, or admin dashboard.
