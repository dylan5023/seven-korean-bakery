# 7 Korean Bakery / 일곱시 떡집

Bilingual (Korean/English) marketing website for 7 Korean Bakery, a Korean rice cake bakery in Coquitlam, BC. Phase 1 is frontend-only: no backend, database, auth, or payments.

## Install

```bash
npm install
```

## Run

```bash
npm run dev     # dev server at http://localhost:3000
npm run build   # production build
npm run lint    # lint
```
